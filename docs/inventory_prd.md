# PRD 요약 — 공구·부품 재고관리

## 목적
- 2D 도면을 3D 모델로 바꾸는 대시보드에 붙는 재고관리 기능이다.
- 작업 전에 부족한 부품과 공구를 미리 찾는 것이 목표다.
- 작업자가 영어 코드를 외우지 않도록 목록은 모두 한글 표기로만 보여 준다.

## 화면 구성 (탭 4개)
1. **작업 준비 점검:** 부품과 공구의 현재고와 보관위치만 보여 준다. 재고가 0이면 빨간색이고, 검색과 '현재고 목록 복사'가 된다.
2. **공구 재고관리:** 공구를 등록·수정·삭제한다. 현재고, 안전재고, 공급업체, 단가를 관리하고 종류별 수와 재고 금액을 집계한다.
3. **부품 재고관리:** 분류, 필요 수량, 현재고, 조달 방식, 사용 공구를 관리한다. 부품번호와 작업번호 칸은 없고, 한글 표기로 부품을 구분한다.
4. **입출고 기록:** 공구와 부품을 입고·출고하면 재고가 자동으로 바뀐다. 구입처와 단가를 넣으면 금액이 자동 계산된다.

## 주요 규칙
- **공구 상태:** 재고가 0이면 소진, 안전재고 이하이면 부족, 그 외는 정상이다.
- **부품 상태:** 필요 수량보다 재고가 적으면 부족, 남는 양이 안전재고보다 적으면 여유 적음, 그 외는 충분이다.
- **한글 표기:**
  - 공구는 코드 앞 영문을 한글로 바꾼다. 예: EM-10 → 엔드밀-10
  - 부품은 비워 두면 '분류-001' 형식으로 번호가 붙는다.
- **입력 막기:** 코드나 한글 표기가 중복되면 저장되지 않고, 현재고보다 많이 출고할 수 없다.
- **삭제·취소:** 버튼을 두 번 눌러야 실행되고, 기록을 취소하면 재고도 되돌아간다.

## 기술 조건과 한계
- 서버 없이 HTML 파일 하나로 동작한다.
- 데이터는 사용하는 브라우저에만 저장되므로, 다른 PC로 옮기거나 공유하려면 백업 텍스트를 써야 한다.
- CSV 복사로 엑셀에 붙여넣을 수 있다.

## 향후 과제
1. 3D 모델의 부품 목록 자동 불러오기
2. 공구 필요량 계산 화면
3. 여러 작업자가 같이 쓰는 공유 저장소
4. 발주 요청서 생성
5. 재고 추이 차트
