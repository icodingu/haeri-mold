금형 이력 관리 v1.7

해커톤 데모 · 2026-11-21 · 단순화한 금형 형상과 예시 데이터

입력 방법 (전체)

A 금형 등록·수정

  1. 새 금형: 금형 목록의 '금형 등록'을 누릅니다. 금형번호와 품명은 필수이고, 금형번호는 ERP와 같은 형식으로 씁니다.
  2. 설비: 수평·수직을 고릅니다. 수평은 톤수(450·220·170·110톤)를 고르면 같은 톤수의 설비만 현재 설비로 고를 수 있습니다. 수직은 VE01~15 중 전용 설비를 고릅니다.
  3. 원재료: 원재료 이름(예: PP GF30)을 쓰고 GF30% 함유와 Non GF 중 하나를 고릅니다. 노후도 기준 수명(50만 타, 100만 타)이 이걸로 정해집니다.
  4. 나머지: 제작 업체, 제작일, 캐비티, 누적 쇼트, 도면 Rev, 탕도, 슬라이드를 채웁니다.
  5. 고칠 때: 금형 정보 칸의 '금형 정보 수정'에서 제작 업체, 제작일, 원재료, 누적 쇼트, 도면 Rev, 현재 설비를 바꿉니다.

B 이력 등록 (공통)

  1. 목록에서 금형을 고르고 '이력 등록'을 누릅니다.
  2. 필수: 유형, 일자, 제목. 기타 유형이면 유형 이름도 씁니다(예: 세척, 부품 교체).
  3. 3D 부위: '3D에서 찍기'를 누르고 고친 부위를 누르거나, 목록에서 고릅니다.
  4. 작업 구분: 사내에서 했으면 내주(작업 부서), 업체에 맡겼으면 외주(업체명 필수)를 고릅니다. 한 번 쓴 업체명은 다음부터 목록에서 고를 수 있습니다.
  5. 비용: 금액(원)과 부담처(사내·업체·고객)를 적습니다. 비용이 없으면 비워 둡니다.
  6. 상태: 요청, 진행 중, 완료 중 하나를 고릅니다.

C 유형별 추가 칸

  1. 치수수정: 측정 부위마다 변경 전, 변경 후, 공차(mm)를 한 줄씩 넣습니다.
  2. 수리: 고장 증상, 원인, 조치 내용, 수리 기간.
  3. 설계변경: 변경 요청 번호(ECO), 요청 부서, 변경 전·후 Rev.
  4. 점검: 결과(양호·주의·불량)와 누적 쇼트. 누적 쇼트를 넣으면 노후도가 갱신됩니다.
  5. 이관: 보낸 설비는 자동으로 채워지고, 받는 설비는 호환 설비 중에서 고릅니다. 저장하면 현재 설비가 바뀝니다. 수직 금형은 옮길 수 없습니다.

D 도면·사진, 반복 입력

  1. 첨부: 첨부 종류(도면, 수정 전·후 사진, 성적서·견적서)와 도면 Rev를 고르고 파일을 고릅니다. 이미지와 PDF, 한 파일 1.5MB 이하이며 사진은 자동으로 줄여 저장합니다.
  2. 같은 일이 또 생기면: 예전 카드를 펼쳐 '이 이력 복사해서 새로 등록'을 누릅니다. 날짜, 치수, 비용만 고치면 됩니다.
  3. 저장 후: 타임라인 맨 위에 쌓이고, 요약·판단·금형 목록의 상태가 다시 계산됩니다.
  4. 저장 위치: 대시보드 안에서 열면 클라우드에 자동 저장되고 팀원과 함께 봅니다. 이 파일만 따로 열면 지금 쓰는 브라우저에만 저장됩니다.
